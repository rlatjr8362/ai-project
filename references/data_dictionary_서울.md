## 3. 참고

- ⚠ **점포수 컬럼명 주의**: 자치구 단위 파일은 `전체_점포_수`, 행정동 단위 파일은 `점포_수` — 같은 뜻인데 이름이 다름 (25~29번 코드에서 계속 주의하면서 처리함)
- 행정동_코드(8자리) // 1000 = 자치구_코드(5자리) — 행정동 데이터에서 자치구를 역산할 때 이 공식 사용
- 원본 파일들의 "기준_년분기_코드"는 자치구/서울시 단위 20211~20261(21개 분기), 행정동/상권 단위는 20211~20254(2026년 1분기 미공개)
