# 데이터 설명서 (Data Dictionary)

`notebooks/1.0-eda.ipynb`에서 이 문서를 참조한다. `data/processed/`의 두 핵심 테이블(자치구 종합표, 행정동 후보표)에서 실제로 쓰인 컬럼을 정리했다.

## 원본 데이터 출처

서울시 상권분석서비스(우리마을가게 상권분석서비스), 서울시 열린데이터광장(data.seoul.go.kr) 제공, 공공누리 제1유형(출처표시)에 따라 이용. 원본 파일은 `[유통] 서울시 골목상권분석정보/`에 있으며 7종(추정매출·점포·직장인구·상주인구·유동인구·집객시설·상권변화지표)을 자치구·행정동 단위로 사용했다.

## 공통 식별자

| 컬럼 | 의미 |
|---|---|
| `자치구_코드`, `자치구_코드_명` | 서울시 25개 자치구의 행정 코드와 이름 |
| `행정동_코드`, `행정동_코드_명` | 서울시 행정동(약 420개)의 행정 코드와 이름 |

## 대상 변수 (매출)

| 컬럼 | 의미 | 산출식 |
|---|---|---|
| `카페1개당_평균매출` | 카페 1개 점포당 평균 추정매출(원) — 이 프로젝트의 핵심 설명 대상 | 당월_매출_금액 ÷ 점포_수 |
| `카페1개당_평균매출_억원` | 위 값을 억원 단위로 표시 | 카페1개당_평균매출 ÷ 1억 |
| `성장률` | 최근 분기 대비 매출 증감률(%) — 행정동 표에서 최근 4개 분기 기준 | (최근분기 매출 − 4분기전 매출) ÷ 4분기전 매출 × 100 |

## 배후 수요 지표 (자치구 단위, 회귀모델에 사용)

| 컬럼 | 의미 |
|---|---|
| `총_직장_인구_수` | 해당 자치구에서 근무하는 직장인 수 |
| `총_상주인구_수` | 해당 자치구에 거주(주민등록)하는 인구 수 |
| `총_가구_수` | 해당 자치구의 가구 수 — 주거지 성격을 나타내는 지표로 사용 |
| `총_유동인구_수` | 통행량 기반 유동인구 수 |
| `집객시설_수` | 관공서·병원·학교·백화점 등 사람을 끌어모으는 시설의 수 |
| `지하철_역_수` | 해당 자치구 내 지하철역 수 |
| `전체_점포_수` | 업종 불문 전체 점포 수 |
| `운영_영업_개월_평균` | 점포의 평균 운영 개월 수 — 상권의 안정성을 간접적으로 보여주는 지표 |
| `점포_수` | 카페(커피-음료, CS100010) 업종 점포 수 |

## 시간대·컨셉 지표

| 컬럼 | 의미 |
|---|---|
| `아침_비중` / `점심_비중` / `저녁_비중` | 하루 6개 시간대 매출 중 아침(06~11시)·점심(11~14시)·저녁(17~21시) 매출이 차지하는 비중(%) |
| `컨셉_적합도` | 아침_비중 + 점심_비중 + 저녁_비중의 단순 합 — 하루 중 "세 끼 시간대"에 매출이 얼마나 몰려 있는지의 총량. 다만 세 시간대에 고르게 퍼진 정도는 반영하지 못한다는 한계가 있어 `3.0-insights.ipynb`에서 균형점수로 보완한다 |
| `균형점수` | (파생 변수, `3.0-insights.ipynb`에서 계산) 아침·점심·저녁 매출 비중이 세 시간대에 얼마나 고르게 분산되어 있는지를 엔트로피 공식으로 0~100점화한 지표. 100에 가까울수록 특정 시간대에 쏠리지 않고 균등하다 |

## 범주형 지표

|---|---|
| `상권_변화_지표_명` | 서울시가 분류한 상권 상태 — 다이나믹 / 정체 / 상권확장 / 상권축소 4가지 범주(정확한 산정 기준은 원본 서비스 문서로 확인하지 못해 서울시 분류값을 그대로 사용) |
