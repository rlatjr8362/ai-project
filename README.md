# 서울시 신규 플래그십 카페 입지 분석

서울시 상권분석서비스 데이터로 "왜 어떤 자치구는 카페 매출이 높은가"를 설명하는 회귀모델을 만들고, 자치구 단위 모델을 행정동 단위 실제 입지 후보 선정까지 확장한 프로젝트입니다.

## 문제 정의

- **발견하고 싶은 문제**: 내가 서울에 카페를 새로 연다면 어느 상권이 가장 적절할까? 자치구 25개 단위에서 카페 매출을 설명하는 공통 특징을 회귀모델로 찾아내고, 그 설명력을 행정동 420개 단위까지 내려서 조건은 좋지만 아직 저평가된 실제 입지 후보를 데이터로 좁힐 수 있는가?
- **이유**: 매출 스냅샷만 보면 이미 꺾이고 있는 상권을 놓치기 쉽고, 표본이 자치구 25개로 적어 일반적인 train/test 분할로는 추정이 불안정하다. LOOCV로 검증한 회귀모델과 행정동 드릴다운을 함께 써야 신뢰할 수 있는 입지를 골라낼 수 있다.

## 데이터

- **파일**: `data/raw/` 아래 서울시 상권분석서비스(우리마을가게 상권분석서비스) 추정매출·점포·직장인구·상주인구·유동인구·집객시설·상권변화지표 7종 (자치구·행정동 단위)
- **컬럼 사전**: `references/data_dictionary.md`
- **출처**: 서울시 열린데이터광장(data.seoul.go.kr), 공공누리 제1유형(출처표시)
- **규모**: 자치구 종합표 25행 × 22열, 행정동 후보표 420행 × 15열, 결측치 없음
- **분석 단위**: 두 층 — 자치구 단위(25개)는 서울 전체 그림과 회귀모델에, 행정동 단위(420개)는 실제 입지 후보를 좁힐 때 사용
- **시점**: 자치구 단위 2021년 1분기~2026년 1분기, 행정동 단위는 2025년 4분기까지만 공개되어 두 레벨의 분석 시점이 약 1개 분기 어긋나 있음
- 용량 문제로 원본 CSV·ZIP 파일은 저장소에 포함하지 않았습니다(`.gitignore`에 `data/raw` 등록). 분석을 재현하려면 서울 열린데이터광장에서 원본을 내려받아 위 경로에 위치시켜야 합니다.

## 분석 파이프라인

1. **`1.0-eda.ipynb`** — 데이터 이해(이 데이터를 고른 이유, 행과 컬럼의 의미), 결측치·이상치 점검, 대상 변수(카페1개당 평균매출) 분포, 변수 간 관계 탐색, 상권 변화 지표별 매출 차이
2. **`2.0-modeling.ipynb`** — 기준선(직장인구 1개 변수) → 개선모델(3개 변수) 탐색, 선택편향(다중비교) 위험 점검, 모델 가정 점검(다중공선성·계수 유의성), 잔차로 저평가/고평가 지역 확인, 랜덤포레스트와의 비교
3. **`3.0-insights.ipynb`** — 표본 안정성 필터, 매출 Top20 + 역성장 제외, 균형점수(엔트로피) 보완, 민감도 분석, 최종 후보 3곳 확정, 자치구 모델과의 교차 확인, 상관관계 vs 인과관계, 종합 결론과 비즈니스 인사이트, 한계

## 핵심 결과

- **최종 채택 모델**: `카페1개당_평균매출 ~ log(총_직장_인구_수) + 총_가구_수 + 집객시설_수` (선형회귀)
- **성능**: 전체학습 R²=0.85, LOOCV R²=0.78 (과적합 정도 0.08 수준)
- **모델 가정 점검**: VIF 세 변수 모두 3 미만(log_직장인구 2.01, 총_가구_수 2.08, 집객시설_수 2.99), 계수 유의성 세 변수 모두 p<0.05
- **대안 모델 비교**: 같은 변수로 랜덤포레스트를 학습하면 전체학습 R²는 0.93으로 더 높지만 LOOCV R²는 0.41로 떨어져 과적합이 뚜렷 — 선형회귀 선택이 타당함을 뒷받침
- **선택편향 점검**: 의미 없는 난수 변수를 추가하는 50회 실험에서 우연히 LOOCV가 좋아 보인 경우가 12회 있어, 변수 선택 편향 위험이 0은 아니라는 점까지 확인
- **최종 후보 3곳**: 소공동(매출 규모 1위), 잠실2동(성장률 1위), 서초4동(균형점수 1위 — 시간대에 관계없이 고르게 팔리는 입지)
- **자치구-행정동 교차 확인**: 서초4동이 속한 서초구는 자치구 모델 잔차 순위가 25개 중 17위로 중하위권 — 자치구 단위 설명력이 행정동 단위 후보 선정까지 그대로 이어지지 않는다는 근거
- **인과관계 아님을 명시**: 역인과 가능성, 교란변수(상권 성숙도·임대료 등 미측정 요인), 단면 데이터의 한계로 상관관계 수준의 설명임을 리포트에도 명시

## 한계

- 임대료·권리금·경쟁 카페 밀도가 데이터에 없어, 매출만으로 순이익 기준 입지 비교는 할 수 없음
- 상관관계이지 인과관계가 아님(단면 데이터) — 개입(intervention) 질문에는 답할 수 없음
- 표본이 자치구 25개, 행정동 후보 중 잠실2동은 24개로 세 후보 중 가장 작음
- 행정동 데이터가 2025년 4분기까지라 자치구(2026년 1분기) 대비 약 1개 분기 시차 존재
- 컨셉_적합도·상권_변화_지표_명의 정확한 산정 기준은 서울시 원본 서비스 문서로 확인하지 못해, 제공된 분류값을 그대로 사용
